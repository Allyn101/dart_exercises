## Scenario
This program calculates a student's canteen order subtotal, applies a student discount, and demonstrates Dart variables, data types, operators, and console output.

## Concepts Demonstrated
- int, double, String, and bool variables
- Arithmetic operators
- Comparison operators
- Integer division and remainder
- Console output using print() and string interpolation

## How to Run
Run the following command in the project directory:

```bash
dart run
```
